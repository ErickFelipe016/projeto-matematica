# Matemática Inclusiva: caminhos para a autonomia no supermercado

Projeto educativo que apresenta uma proposta de carrinho de compras inteligente para apoiar pessoas com deficiência visual na circulação e na localização de produtos em supermercados.

## Objetivo

Relacionar conhecimentos matemáticos — como localização, distância, direção e organização espacial — à tecnologia e à inclusão social, incentivando a criação de soluções acessíveis para situações do cotidiano.

## Conteúdo do projeto

- **Componente curricular:** Matemática, articulada à tecnologia e à inclusão social.
- **Elementos de competência:** aplicação de conhecimentos de localização, distância e direção na elaboração de soluções acessíveis, com investigação de problemas e comunicação colaborativa.
- **Marcas formativas:** domínio técnico-científico; visão crítica; autonomia digital; comunicação e colaboração; atitude criativa e empreendedora.
- **Etapa 1 — Ação:** investigação e planejamento.
- **Etapa 2 — Reflexão:** acessibilidade e autonomia.
- **Etapa 3 — Nova ação:** estruturação da proposta e contribuição social.

## Estrutura dos arquivos

```text
matematica_inclusiva/
├── index.html   # Estrutura e conteúdo da página
├── style.css    # Estilos, cores, layout e responsividade
├── script.js    # Recursos de acessibilidade e leitura em voz alta
└── README.md    # Documentação do projeto
```

## Como executar

1. Baixe ou clone o projeto e abra a pasta no Visual Studio Code.
2. Verifique se `index.html`, `style.css` e `script.js` estão na mesma pasta.
3. Abra `index.html` diretamente em um navegador.
4. Opcionalmente, utilize a extensão **Live Server** no VS Code para atualizar a página automaticamente durante a edição.

Não é necessário instalar Node.js ou dependências para executar esta página estática.

## Recursos de acessibilidade

- Leitura em voz alta de trechos selecionados, usando a síntese de voz disponível no navegador.
- Botão para ler o conteúdo da página.
- Alternância para alto contraste.
- Controle para aumentar o tamanho do texto.
- Link para pular diretamente ao conteúdo principal.
- Layout adaptável a computadores e celulares.

A disponibilidade e a qualidade da voz em português dependem do navegador e das vozes instaladas no dispositivo.
